# Trade Copier

Project conventions for the MT5 trade-copier pipeline. Auto-loaded every session.

## Project root
- Repo: `/opt/data/trade-copier/`
- Compose: `/workspace/docker-compose.yml` (main host) or `/opt/data/trade-copier/docker-compose.yml` (local copy)
- `.env` at `/opt/data/trade-copier/.env`

## Architecture
```
listener → router → bridge → MT5 (observe-only)
```

## Key paths
- Router: `/opt/data/trade-copier/router/router.py`
- Bridge: `/opt/data/trade-copier/bridge/bridge.py`
- Listener: `/opt/data/trade-copier/listener/listener.py`
- Channel state (inside container): `/data/channel_state.json`
- Container logs: `docker logs <name> --tail 30`

## Diagnostics first
- Always check container logs before editing code: `docker logs router --tail 30`
- Pipeline status: `docker ps --format "table {{.Names}}\t{{.Status}}"`
- Check `.env` vars: `grep -v '^#' /opt/data/trade-copier/.env | grep -v '^$'`

## Edit conventions
- **Prefer `patch` tool** over `write_file` for existing files (targeted find-and-replace, less token waste)
- **Exception:** root-owned files with 600 permissions → use `write_file` instead
- **Never patch inside running containers** — rebuild from source instead
- Show the diff before applying if changing config or system files

## Common commands
```bash
# Rebuild and restart all containers
docker compose -f /workspace/docker-compose.yml build && docker compose -f /workspace/docker-compose.yml up -d

# Check router LLM calls
docker logs router --tail 20 | grep -E 'HTTP Request|parsed|Rejected'

# Check bridge trade execution
docker logs bridge --tail 20 | grep -E 'trade|order|position|entry'

# Check listener message flow
docker logs listener --tail 20 | grep -E 'Pushed|Got difference|delete'
```
